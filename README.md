# ✈️ Airline Management System

A web-based Airline Management System developed as a collaborative university database project for **CSE370 – Database Systems at BRAC University**.

The project focuses on managing airline-related information through a web application supported by a relational database. It demonstrates the practical application of database design, SQL queries, and web development technologies.

## 📌 Project Overview

The Airline Management System is designed to organize and manage airline operations efficiently. It provides a web-based interface for handling airline-related data and performing database operations.

This project was developed collaboratively, combining database management and web development concepts to build a functional airline management application.

## 🛠️ Technologies Used

| Technology | Purpose |

## ✨ Key Features

- Flight information management
- Passenger information management

## 🗄️ Database Implementation

The project uses a relational database to store and manage airline-related information.

Database concepts implemented include:

- Relational database design
- Table creation and management
- Primary keys and foreign keys
- Relationships between database tables
- SQL queries for data manipulation
- Data insertion, updating, deletion, and retrieval

## ⚙️ Installation and Setup

Follow these steps to run the project on your local machine.

### 1. Prerequisites

Install the following software:

- [XAMPP](https://www.apachefriends.org/)
- [Visual Studio Code](https://code.visualstudio.com/) (or another code editor)
- A web browser

### 2. Clone the Repository

```bash
git clone https://github.com/Fayaz2010/CSE370-Airline-Management-System.git
```

### 3. Move the Project Folder

Move the cloned project folder into the XAMPP `htdocs` directory.

### 4. Start XAMPP Services

Open XAMPP Control Panel and start:

- Apache
- MySQL

### 5. Import the Database

1. Open [http://localhost/phpmyadmin](http://localhost/phpmyadmin).
2. Create a new database using the database name required by the project.
3. Select the database.
4. Import the project's `.sql` file.

### 6. Configure Database Connection

Check the PHP database connection file and update the database host, username, password, and database name according to your local XAMPP configuration.

### 7. Run the Application

Open your browser and visit:

```text
http://localhost/CSE370-Airline-Management-System/
```
